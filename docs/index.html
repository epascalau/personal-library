🛠️ Generating Documentation from Source

You can regenerate both documentation suites at any time using the bundled npm scripts:

  • npm run docs:ts — Generates the TypeScript API Reference in docs/typescript/ using TypeDoc.
  • npm run docs:java — Generates the Java Spring Boot Javadoc in docs/javadoc/.
  • npm run docs — Builds both TypeScript and Java documentation concurrently in one command.
