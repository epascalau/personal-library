              fileSize: number;
              mimeType?: string;
          },
      ): Promise<DocumentRecord>

      Ingests a new document into the library with automated BibTeX extraction and dual-model AI summarization.

      WHAT: Issues a POST to /documents with file payload, base64 data, and metadata. WHY: Ingestion is a computationally intensive pipeline involving file storage, text extraction, chunk vectorization into Qdrant, and dual LLM synthesis (Llama 3.3 and Mistral Large). A generous 180-second timeout prevents premature disconnection, while 0 retries ensures that documents are never accidentally ingested twice.
