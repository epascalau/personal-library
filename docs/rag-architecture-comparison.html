Retrieval-Augmented Generation (RAG) Architecture

Comparative Evaluation: Personal Library & AI Research Engine vs. Canonical Enterprise Reference Architecture

🧠 EXPERT • Research-grade, assumes familiarity with RAG literature

1. Executive Summary: Evolutionary Classification

In modern Artificial Intelligence (AI) systems literature (Gao et al., 2024: "Retrieval-Augmented Generation for Large Language Models: A Survey"), RAG systems evolve across three progressive paradigms:

  • Naive RAG: Standard linear pipeline of text splitting, single-modality dense vector embedding, cosine similarity search, and prompt augmentation.
  • Advanced RAG: Introduces boundary-aware chunking, pre-retrieval query routing, and post-retrieval verification.
  • Modular RAG: An enterprise-grade, multi-stage architecture featuring Hybrid Search (Dense Vector + Sparse Lexical BM25), Cross-Encoder Re-Ranking, Parent-Child Context Expansion, and automated RAG Triad (Ragas) Quality Reflection.
Where Personal Library Sits: Our current implementation operates as a highly mature Advanced-Lean RAG Architecture with native Qdrant vector database integration, dual-model LLM benchmarking (Llama 3.3 70B & Mistral Large 2411), strict document GUID isolation, and an interactive UI citation drawer that exceeds standard reference implementations.

3. Mathematical Formulations of Reference RAG Enhancements

1. Reciprocal Rank Fusion (RRF) for Hybrid Dense + Sparse Search

Combining dense semantic vector rankings with sparse keyword rankings (Cormack et al., 2009):

$$\text{RRF}(d) = \frac{1}{k + R_{\text{dense}}(d)} + \frac{1}{k + R_{\text{sparse}}(d)}, \quad \text{where } k = 60$$

2. Cross-Encoder Re-Ranking Score

Full token-to-token cross-attention between query $q$ and candidate chunk $c$:

$$s_{\text{cross}}(q, c) = \sigma\left( W \cdot \text{Transformer}([q \;\|\; \text{[SEP]} \;\|\; c]) \right)$$

3. Ragas Faithfulness Metric

Measuring whether generated statements $S(A)$ are strictly entailed by retrieved context $C$ (Es et al., 2023):

$$\text{Faithfulness}(A, C) = \frac{| \{ s \in S(A) \mid C \vdash s \} |}{|S(A)|}$$

4. Recommended Modular RAG Evolution Roadmap

To upgrade Personal Library from its current Advanced-Lean baseline to a Full Modular Reference Architecture:

  1. Conversational Query Reformulation: In multi-turn chat sessions, use a lightweight prompt to rewrite pronouns and follow-up queries into self-contained search statements before hitting Qdrant.
  2. Small-to-Big (Parent-Child) Indexing: Store small 150-token child vectors in Qdrant with a pointer to their 800-token parent paragraph, returning the parent text to the LLM context.
  3. Qdrant Hybrid Search: Leverage Qdrant's native sparse vector payload support to execute BM25 alongside dense cosine embeddings in a single fused call.
