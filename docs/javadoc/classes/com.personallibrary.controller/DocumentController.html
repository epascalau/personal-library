@GetMapping @Operation(summary = "Retrieve and filter paginated document list (List Report Floorplan)")
public ResponseEntity<PaginatedResponse<DocumentResponse>> getDocuments(Object param)

List Report Floorplan query: Supports single or combined filters: file name, document name, author, edition, format, content. WHAT: Executes a dynamic multi-attribute search across both relational metadata and document full-text, applying pagination and custom sorting. WHY: Paginating and filtering on the database level prevents high-memory overhead on the client, while supporting fuzzy case-insensitive substring queries aligns with the SAP Fiori List Report standard. /

Parameters:
fileName - Filter for physical file name.
title - Filter for bibliographic title.
author - Filter for author name.
edition - Filter for edition.
format - Filter for file format.
content - Full-text search query.
page - Page number (1-based).
pageSize - Page size.
sortBy - Sort field.
sortOrder - Sort direction ("asc" or "desc").
Returns:
Paginated list of document responses.

uploadDocument
@PostMapping(consumes = MediaType.MULTIPART_FORM_DATA_VALUE) @Operation(summary = "Upload document (single file only) and trigger automated pipeline")

Uploads a single file and triggers automated pipeline: file persistence, BibTeX extraction, Qdrant vector indexing, and dual model summaries. Parameters:

bibtexJson - Optional JSON-encoded BibTeX metadata.
Returns:
{@link DocumentResponse} representing the new document.

overwriteVersion
@PutMapping(value = "/{guid}", consumes = MediaType.MULTIPART_FORM_DATA_VALUE) @Operation(summary = "Upload replacement version (overwrites active document in-place, preserves GUID)")
public ResponseEntity<DocumentResponse> overwriteVersion(Object param, Object param, required = false)

Overwrites active document content and metadata in-place while keeping its existing GUID. WHAT: Replaces the stored file asset and/or metadata, increments `versionNumber`, re-chunks text, re-embeds vectors into Qdrant, and updates the existing document entity. WHY: Stable GUID preservation ensures existing citation links and external URLs remain valid across document revisions, reflecting academic library versioning standards. /

Parameters:
guid - Document GUID to overwrite.
file - Optional replacement file asset.

Updated {@link DocumentResponse}.
