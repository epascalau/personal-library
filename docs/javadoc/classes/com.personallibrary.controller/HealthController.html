health
@GetMapping({"/health", "/status"}) @Operation(summary = "Aggregate backend health", description = "Reports Ollama, MongoDB, and Qdrant vector store readiness")
public Object>> health()

Reports detailed health status of application, AI models, vector database, and MongoDB. WHAT: Probes the local Ollama daemon's `/api/tags` endpoint for reachability, counts indexed documents via MongoDB, and assembles uptime, model, vector store, and build metadata into a single JSON payload matching the Node.js Integrated Gateway's `/api/v1/health` contract. WHY: The frontend's `RestBackendAdapter` probes `/health` on whichever backend target is selected (Integrated Gateway or Direct Java Spring Boot); without this endpoint, the Java backend returned a 404 on every 30-second poll, forcing a slower fallback probe and generating log/network noise. /

Returns:
JSON health payload with `status: "UP"` when reachable, mirroring the gateway's schema.
