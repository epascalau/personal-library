interface DocumentRepositoryCustom

public interface DocumentRepositoryCustom

Custom repository fragment providing the dynamic multi-predicate document search backing the SAP Fiori List Report floorplan. <p>The filter combination is genuinely dynamic: every criterion is optional and any subset may be supplied. Such a query cannot be expressed as a static {@link org.springframework.data.mongodb.repository.Query} string, so it is assembled programmatically against {@link org.springframework.data.mongodb.core.MongoTemplate}.</p> /
