class DocumentRepositoryCustomImpl

public class DocumentRepositoryCustomImpl implements DocumentRepositoryCustom

{@link MongoTemplate} backed implementation of the dynamic document search. <p>Criteria are appended only for the filters the caller actually supplied, which keeps the emitted MongoDB query minimal and index friendly. All user supplied terms are quoted via {@link Pattern#quote(String)} so that regular expression metacharacters in search input are treated as literals rather than altering the query semantics.</p> /
