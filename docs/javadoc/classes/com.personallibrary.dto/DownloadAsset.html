public record DownloadAsset

Lightweight descriptor pointing to a physical file asset ready to be streamed to a client, covering both the currently active document version and preserved historical snapshots. WHAT: Pairs a disk path with the original file name the client should see in its Content-Disposition header. WHY: Keeps the download resolution logic in {@code DocumentService} decoupled from the HTTP streaming mechanics in {@code DocumentController}. /
