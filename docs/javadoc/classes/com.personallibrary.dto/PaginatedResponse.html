public PaginatedResponse<T> of(List<T> items, long totalCount, int page, int pageSize)

Factory method computing total pages and constructing a typed PaginatedResponse. WHAT: Calculates totalPages as `ceil(totalCount / pageSize)` and builds the PaginatedResponse instance. WHY: Centralizes pagination math in one location, avoiding repetitive calculation across services and controllers. /

Parameters:
items - Current page records list.
totalCount - Overall matching records across the entire dataset.
page - Current 1-based page index.
pageSize - Maximum records per page.
<T> - Record item type.
Returns:
Complete PaginatedResponse container.
