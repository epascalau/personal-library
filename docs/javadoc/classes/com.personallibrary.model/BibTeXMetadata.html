public String toRawBibTeX()

Serializes this metadata object into an RFC-compliant raw BibTeX string format. WHAT: Assembles a standard `@entryType{bibKey, ...}` bibliographic block with indented key-value attributes. WHY: Enables researchers to copy-paste formatted BibTeX directly into LaTeX manuscripts, Zotero, Mendeley, or Overleaf workflows without manual syntax reformatting. /
