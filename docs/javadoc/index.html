System Architecture & Package Overview

The Personal Library backend is an enterprise-grade document management and generative AI service orchestrating automated BibTeX metadata extraction, dual-model analytical summaries (Ollama Llama 3.3 and Mistral Large), in-place GUID version management, and high-precision RAG vector retrieval using Qdrant.
